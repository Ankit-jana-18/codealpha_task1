# Credit Scoring Machine Learning Project

## 📌 Project Overview
This project predicts credit risk using machine learning algorithms.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 🤖 Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest

## 🔍 Features
- Data preprocessing
- Missing value handling
- Feature engineering
- Model evaluation
- ROC-AUC comparison
- Confusion matrix
- Feature importance visualization

## 📂 Dataset
The project uses the `cs_training.csv` dataset for credit risk analysis.
